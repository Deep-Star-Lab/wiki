# Morphological Tokenizer for Turkish

!!! note "Draft page"
    This page is a skeleton built from the project short description; the maintainers will add the details.

## Summary

This project develops a [tokenizer](../resources/glossary.md#tokenizer) template that takes the morphological structure
and other requirements of Turkish into account. The goal is for the tokenizer to connect directly to a language model's first layer.

## Why?

Turkish is an [agglutinative language](../resources/glossary.md#agglutinative): meaning is built by affixes attached to a root.
A tokenizer that accounts for this structure ([morphology](../resources/glossary.md#morphology)) gives a starting point
that fits the needs of the language.
