## Wiki'ye Katkıda Bulunma

```bash
# Example: clone the repository and install dependencies
git clone https://github.com/Deep-Star-Lab/wiki.git
cd wiki
# Gerekli paketleri kur
pip install -r requirements.txt
# Build the site locally
mkdocs serve
```
