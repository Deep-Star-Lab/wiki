# Overview

This page summarizes the basic steps for people who are new to the Deep Star Lab community.

## Requirements

- A GitHub account
- Google Colab or Kaggle Notebook
- Basic command-line knowledge
- A Hugging Face account

## Contributing to the Wiki

```bash
# Clone the repository and install dependencies
git clone https://github.com/Deep-Star-Lab/wiki.git
cd wiki
pip install -r requirements.txt
# Build and preview the site locally
mkdocs serve
```
